# SPEC

> /goal은 이 파일의 "수용 기준" 체크박스를 완료 판정 기준으로 씁니다. 빈칸이 있으면 Claude가 한 번에 모아서 물어봅니다.

## 제품
- 한 줄 설명: 설치·가입 없이 가까운 기기끼리 파일을 직접 주고받는 P2P 전송 웹앱(PWA). 수십 GB도 끊겨도 이어받습니다.
- 타깃 사용자: 휴대폰·PC·태블릿 사이로 큰 파일을 자주 옮기는 개인 사용자.
- 사용자가 페이지에서 해야 할 단 하나의 행동(CTA): 근처 기기를 탭하고 파일을 고른다(또는 끌어다 놓는다).

## 페이지 / 섹션
앱은 단일 화면입니다. 템플릿의 "Hero"는 상단 내 기기 영역에 대응합니다.
1. Hero — 내 기기 이름, 연결 상태("연결됨" / "다시 연결 중…")
2. 근처 기기 — 같은 네트워크의 기기 목록(탭하면 파일 선택, 드래그앤드롭 대상)
3. 전송 — 기기별 진행률, 속도, 남은 시간, 취소. 진행 중 연결이 끊기면 자동 재개
4. 수락 다이얼로그 — 보낸 기기 이름, 기기 ID 지문(20자), 파일 목록·총 크기, 이름 중복 경고, 수락/거절
5. 받은 파일 — 완료 항목을 눌러 저장

## 디자인 방향 (레퍼런스 사이트 없이)
- 분위기 단어 3개: 차분함, 믿음직함, 가벼움
- 사용 상황: 한 손으로 휴대폰을 쓰면서 PC로 보낼 때, 책상 위에서 두 기기를 번갈아 볼 때
- 피하고 싶은 것: 보라 그라데이션, 이모지 아이콘, 광고·팝업 느낌, 기술 용어(ICE, TURN, SCTP 등) 노출
- 좋아하거나 싫어하는 색: 푸른 계열 단색 중심(기본 파랑 + 연한 파랑 면 + 짙은 남색 글자). 보라·네온 제외. 오류만 붉은 계열
- 무드 레퍼런스: 절제된 여백, 큰 터치 영역, 단일 강조색

## 브랜드
- 이름: Radius
- 톤: 차분하고 기술적. 짧은 행동 지시형 한 문장(예: "같은 Wi‑Fi에 연결해 주세요")
- 금지: 보라 그라데이션, 이모지 아이콘, 영어·한국어 혼용 문구, 과장된 마케팅 어투

## 언어
- 한국어 전용(문구는 모두 한국어). 다국어(i18n)는 이번 범위 밖.

## 에셋
- `public/assets/`에 넣은 파일: 없음(아이콘은 SVG, 로고는 텍스트 워드마크)
- 카피(실제 문구) 위치: 컴포넌트 내 한국어 문구. 별도 카피 파일 없음

## 알려진 위험 (제품 결정)
- 실행 파일(.exe, .apk 등)을 경고 없이 전송·저장합니다(사용자 결정). 수락 다이얼로그의 보낸 기기 이름·ID 지문 확인이 유일한 방어선입니다.
- 송신 탭을 새로고침하면 파일 핸들이 사라져 같은 파일을 다시 선택해야 합니다.
- 폴더는 파일별 다운로드로 저장됩니다(zip 미지원).
